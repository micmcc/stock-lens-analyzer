# Accumulation good test

## User prompt
Apply the accumulation lens to this chart.

## Expected behavior

- select `ACCUMULATION`
- score in the review or actionable range
- state should be `tightening` or `triggered`, not `basing`
- entry language should be `support entry`, `accumulation trigger`, or `reclaim entry`
- identify the active trigger condition
- include a score interpretation consistent with a usable base
- name a common accumulation pattern
- summary should explain why demand is improving before the full breakout

## What the model should notice

- support shelf or higher low is holding
- participation shows absorption or demand near support
- momentum is turning up from weaker territory without already being too stretched
- price is near value support, reclaiming value, or stabilizing around the EMA
- context should note whether overhead supply is still close

## Failure modes to avoid

- calling a loose, unfinished base actionable
- confusing a pre-breakout accumulation setup with a confirmed breakout
- ignoring repeated support tests that may weaken the base
