# Deep value good test

## User prompt
Apply the deep value lens to this chart.

## Expected behavior

- select `DEEP_VALUE`
- score in the review or actionable range only if clear reversal evidence is present
- state should be `probing`, `reversing`, or `triggered`, not `washed out` if the low is already rejected
- entry language should be `deep-value probe`, `pilot only`, `reversal trigger`, or `reclaim entry`
- identify the active trigger condition
- include a score interpretation consistent with a reversal attempt, not a clean trend setup
- name a common deep-value pattern
- summary should explain both the discount and the remaining trend-damage risk

## What the model should notice

- price is materially discounted into support or lower value
- there is evidence of capitulation, exhaustion, or failed breakdown behavior
- momentum is turning up from oversold or deeply weak territory
- hold/reclaim quality matters more than trend strength at this stage
- context should note overhead supply and whether the move may still be only reflexive

## Failure modes to avoid

- treating every oversold chart as deep value
- ignoring trend damage after a sharp decline
- describing a reflex bounce as a confirmed reversal too early
