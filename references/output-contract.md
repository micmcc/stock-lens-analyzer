# Output contract

Every final answer should contain:

1. Lens used
2. Score table
3. Trigger conditions
4. Score interpretation
5. Common pattern
6. Context awareness
7. Setup state
8. Entry/action zone
9. Invalidation
10. Targets
11. One-line note
12. Short summary

## Single-chart table shape

| Ticker | Score | Action Tier | C1 | C2 | C3 | C4 | C5 | Setup State | Entry/Action Zone | Invalidation | Targets | Note |

## Style rules

- Keep notes concise and decision-oriented.
- Say `watch / wait`, `support entry`, `accumulation trigger`, `deep-value probe`, `reversal trigger`, `breakout trigger`, `retest entry`, `tighten stop`, `trim review`, or similar operational language.
- Prefer zones over single prices unless the level is clearly visible.
- The summary should answer: actionable now, watchlist only, or avoid/review.
