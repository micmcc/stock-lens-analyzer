# Action tiers

Use this shared tiering language unless a lens overrides it.

## Breakout default tiers

- 0–2 = Avoid
- 3–4 = Watch
- 5–6 = Review
- 7–8 = Actionable

### Breakout interpretation notes

- **Avoid** = no valid trigger, weak structure, or poor participation
- **Watch** = developing idea, but confirmation is still missing
- **Review** = close to actionable, but trigger quality or reward/risk still needs work
- **Actionable** = valid trigger or clean retest with room to work

## Distribution default tiers

Interpret the score as urgency to review the exit:

- 0–2 = Hold / no major deterioration
- 3–4 = Tighten review
- 5–6 = Trim review
- 7–8 = High exit urgency

### Distribution interpretation notes

- **Hold / no major deterioration** = structure is still mostly intact
- **Tighten review** = early warning signs are present
- **Trim review** = deterioration is meaningful, but not yet decisive
- **High exit urgency** = breakdown or failed reclaim is now driving the trade

## Accumulation default tiers

- 0–2 = Avoid
- 3–4 = Watch
- 5–6 = Review
- 7–8 = Actionable

### Accumulation interpretation notes

- **Avoid** = no usable base or support response yet
- **Watch** = stabilization is starting, but the base is still immature
- **Review** = accumulation evidence is building, but the trigger still needs respect
- **Actionable** = base is usable and demand is proving itself near support

## Deep Value default tiers

- 0–2 = Avoid
- 3–4 = Watch
- 5–6 = Review
- 7–8 = Actionable

### Deep Value interpretation notes

- **Avoid** = still a falling knife or no credible reversal evidence
- **Watch** = discount is improving, but the reversal is still incomplete
- **Review** = reversal evidence is building, but trend damage is still a real risk
- **Actionable** = washout has likely exhausted and a tradable reversal is underway
